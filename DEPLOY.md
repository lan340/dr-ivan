# Инструкция по запуску сайта-поздравления на вашем хостинге

Этот проект создан как чистое статическое веб-приложение (SPA). Оно не требует серверного бэкенда, баз данных или Node.js на вашем боевом хостинге. Готовые файлы сайта работают абсолютно на любом веб-сервере.

---

## 1. Как отредактировать тексты и шутки

У вас есть **два удобных способа**:

### Способ А: Визуально прямо на сайте (Самый простой)
1. Откройте сайт в браузере.
2. В верхнем правом углу нажмите кнопку **«Редактировать текст»**.
3. Меняйте имя друга, повод, текст письма, воспоминания, шутки или добавляйте новые карточки.
4. Нажмите **«Сохранить»** — изменения мгновенно применятся.
5. На вкладке **«Экспорт и хостинг»** вы можете скачать файл `config.json` или нажать **«Скопировать код»**.

### Способ Б: В файле кода `src/data/initialConfig.ts`
- Откройте файл `src/data/initialConfig.ts` в любом текстовом редакторе (VS Code, Notepad++ и т.д.).
- Все поля снабжены подробными русскими комментариями. Вы можете менять тексты, добавлять новые ачивки или вопросы викторины.

## 2. Сборка проекта для хостинга

Чтобы собрать сайт в готовые файлы для хостинга, выполните в терминале команду:

```bash
npm run build
```

После выполнения команды в корне проекта появится папка **`dist/`**.
Внутри нее будут:
- `index.html` (главная страница)
- папка `assets/` (все скомпилированные стили, скрипты и шрифты)

---

## 3. Размещение на хостинге

### Вариант 1: Обычный shared-хостинг (Beget, Timeweb, Reg.ru, cPanel)
1. Зайдите в панель управления вашего хостинга в **Файловый менеджер** (или подключитесь по FTP / FileZilla).
2. Перейдите в папку вашего сайта (обычно `public_html/` или `www/название_сайта/`).
3. Загрузите **все файлы и папки из вашей локальной папки `dist/`** внутрь `public_html/`.
4. Готово! Сайт сразу доступен по вашему домену.

### Вариант 2: Бесплатный хостинг на Vercel или Netlify
- **Vercel**: Установите утилиту `npm i -g vercel`, введите команду `vercel` и выберите настройки по умолчанию.
- **Netlify**: Просто перетащите папку `dist/` в окно браузера на странице Netlify Drop (drag-and-drop).

### Вариант 3: GitHub Pages
1. В файле `vite.config.ts` укажите параметр `base: './'`.
2. Загрузите проект в репозиторий GitHub и включите GitHub Pages для ветки `gh-pages` или папки `dist`.

---

## 4. Локальный запуск для разработки

Чтобы запустить сайт локально на компьютере для проверки:

```bash
npm run dev
```

Сайт откроется по адресу `http://localhost:3000`.
