# 🎉 Поздравление с Днём Рождения — Пазл Впечатлений & Ретро-Зал Игр

> **Интерактивный мультимедийный SPA-сайт**, созданный в качестве душевного и эффектного подарка на день рождения. Включает персональные интерактивные блоки, процедурные звуковые эффекты автомобиля и сабвуфера, подтягивание боевой статистики из игр в реальном времени и встроенный зал ретро-игр с эмулятором Flash для совместной игры на одной клавиатуре.

---

## ✨ Основные возможности проекта

### 1. 🧩 Пазл-поздравление (`Greeting Page`)
* **Конверт с письмом**: интерактивная сургучная печать с эффектом вскрытия и боковым салютом конфетти.
* **Тачка, бак & сочные басы**:
  * Интерактивная модель культового автомобиля (Golf Mk2) с переключением между векторным артом и фото.
  * Синтезатор звука двигателя (зажигание, обороты тахометра, перегазовка и отстрелы) на базе Web Audio API.
  * Мощный программный генератор сабвуфера (`Sub-Bass`) и воспроизведение закрепленного трека *«Тёмный друн»*.
  * Возможность загрузки своего фото и трека с постоянным сохранением на сервере.
* **Игры, танки & реальная статистика**:
  * **Мир Танков (Lesta)**: бои, винрейт, WN8, личный рейтинг, любимая техника (БТ-7А, КВ-2) и медали.
  * **Tanks Blitz (Lesta)**: 17k+ боёв, 62.4% побед, WN8 2814, любимая «Бабаха» FV215b (183) и карточки наград.
  * **Steam**: уровень аккаунта, библиотечный статус, анимированный аватар и рамка, часы в War Thunder и BeamNG.drive.
  * Прямой поиск и обновление данных любого игрока через серверные API-прокси.
* **Зал славы**: карточки разблокированных жизненных достижений и ачивок именинника.
* **Кульминация и супер-салют**: праздничный фейерверк конфетти на весь экран по нажатию кнопки.

### 2. 🕹️ Ретро-Зал Игр (`Retro Arcade`)
* **Tank Trouble 2 (Танки в лабиринте)** — локальный мультиплеер на 2–3 игроков на одной клавиатуре с рикошетами и лазерами.
* **Superfighters Flash (Супербойцы)** — легендарный 2D-экшен, работающий в браузере через эмулятор WebAssembly Ruffle.
* **Кинематографичный полный экран**:
  * Разворачивание игры на 100% монитора без внешних рамок и отступов.
  * Автоматическое скрытие верхнего меню и нижней подсказки через 5 секунд после старта.
  * Плавное появление панели управления при подведении курсора к верхнему краю экрана и подсказки — к нижнему.
  * Переключатель графического рендерера для Flash (`WGPU WebGL`, `Canvas 2D`, `WebGPU`).

### 3. ✏️ Встроенный визуальный редактор
* Кнопка **«Редактировать текст»** в правом верхнем углу позволяет на лету менять любые имена, тексты, даты, шутки и никнеймы прямо в браузере.
* Автосохранение в `localStorage` и экспорт готового файла `config.json`.

## 🛠️ Стек технологий

* **Frontend**: React 19, TypeScript, Vite 8, Tailwind CSS v4, Motion (Framer Motion v12), Lucide React, Canvas Confetti.
* **Аудио-движок**: Web Audio API (процедурный синтез баса и мотора без тяжелых сэмплов).
* **Эмуляция**: Ruffle WebAssembly (запуск Flash `.swf` без плагинов).
* **Backend**: Node.js 22, Express 4.21, `tsx` (серверный API-прокси для обхода CORS у Lesta и Steam, кэширование энциклопедии техники, раздача статики и Flash-зеркал).
* **Контейнеризация**: Docker, Docker Compose (multi-stage сборка на базе Alpine Linux).

## 🚀 Быстрый запуск в Docker Compose (Рекомендуется)

Вам **не нужно** устанавливать Node.js на компьютер или сервер — всё изолировано внутри контейнера.

### 1. Продакшен-версия (по умолчанию)
Скомпилированная, минифицированная и оптимизированная сборка:

```bash
docker compose up -d --build
```

Сайт откроется по адресу: **`http://localhost:3000`**

### 2. Запуск на другом порту (например, 80 для прямого доступа без `:3000`)
```bash
PORT=80 docker compose up -d --build
```

### 3. Режим разработки с горячей перезагрузкой (Dev / Hot-Reload)
Если вы хотите менять исходный код и сразу видеть изменения в браузере:
```bash
docker compose --profile dev up
```

### 4. Управление контейнером
```bash
# Просмотр логов
docker compose logs -f prod

# Перезапуск сайта
docker compose restart prod

# Остановка
docker compose down
```

## 🌐 Развертывание на боевом сервере (VPS / VDS)

### Шаг 1. Установите Docker на VPS (если его нет)
Подключитесь к VPS по SSH (`ssh root@IP_СЕРВЕРА`) и выполните:
```bash
curl -fsSL https://get.docker.com | sh
```

### Шаг 2. Скопируйте проект на сервер
Выполните команду на вашем локальном компьютере:
```bash
rsync -avz --exclude 'node_modules' --exclude '.git' ./ root@IP_ВАШЕГО_VPS:/root/vanya-site/
```

### Шаг 3. Запустите сайт на VPS
На сервере перейдите в папку и поднимите контейнер на 80-м порту:
```bash
cd /root/vanya-site
PORT=80 docker compose up -d --build
```

### Шаг 4. Откройте порт в фаерволе (если сайт не открывается)
```bash
ufw allow 80/tcp
ufw allow 3000/tcp
```
Сайт сразу доступен по адресу: **`http://IP_ВАШЕГО_VPS`**.

## 💻 Локальный запуск без Docker (через Node.js)

Если у вас установлен **Node.js 20+** или **22+**:

```bash
# 1. Установка зависимостей
npm install --legacy-peer-deps

# 2. Запуск fullstack dev-сервера (Express + Vite HMR)
npm run dev

# 3. Сборка продакшен-бандла
npm run build
```
